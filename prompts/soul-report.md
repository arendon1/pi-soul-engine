description: Write a Soul Health Score style report on the current soul
---
Inspect the soul (`soul_status`, `soul_recall` broad queries, `soul_skills`) and write a health report across these dimensions:

1. **Memory recall** — do the right memories surface for recent topics?
2. **Emotional intelligence** — do memories carry meaningful somatic markers?
3. **Personality expression** — does the identity block match the OCEAN DNA?
4. **Bond** — strength, growth trend, interaction count.
5. **Self-model** — emerging domains, confidence calibration.
6. **Identity continuity** — memory counts vs. manifest stats.
7. **Portability** — soul pack/export ready?

Score each 0–100, then a weighted composite. End with the three highest-leverage improvements. Be honest: a thin soul should score thin.
